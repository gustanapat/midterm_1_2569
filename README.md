# Amazing Thailand — 1 ภาค 1 จังหวัด ไม่ไปไม่รู้

เว็บไซต์ประชาสัมพันธ์ท่องเที่ยวไทยแบบหน้าเดียว นำเสนอ 6 ภาค ภาคละ 1 จังหวัด ได้แก่ น่าน อุบลราชธานี พระนครศรีอยุธยา จันทบุรี กาญจนบุรี และกระบี่ ผู้ชมเลือกการ์ดจังหวัดเพื่อดูข้อมูลเที่ยว กิน พัก และไอเดียเส้นทางสั้น ๆ

## เทคโนโลยี

- HTML, CSS, JavaScript และ TailwindCSS ผ่าน CDN
- ไม่มีเฟรมเวิร์กหรือขั้นตอน build
- ภาพถ่ายจริงเก็บใน `assets/` และแสดงเครดิตพร้อมสัญญาอนุญาตในท้ายเว็บไซต์
- ใช้ AI ช่วยวางแนวทางออกแบบและเรียบเรียงเนื้อหา โดยตรวจข้อมูลสถานที่กับเว็บไซต์การท่องเที่ยวแห่งประเทศไทย

## เปิดดูในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ หรือใช้เซิร์ฟเวอร์ไฟล์คงที่ เช่น:

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000` การโหลด TailwindCSS และฟอนต์ Google ต้องเชื่อมต่ออินเทอร์เน็ต ส่วนภาพถ่ายทั้งหมดอยู่ในโปรเจกต์

## นำไปเผยแพร่

GitHub Pages: เลือกเผยแพร่จาก branch หลักและโฟลเดอร์ `/ (root)`

Netlify: นำเข้า repository แล้วปล่อยช่อง build command ว่าง และใช้ `.` เป็น publish directory

แหล่งข้อมูลของแต่ละจังหวัดเปิดได้จากปุ่ม “ดูข้อมูลจังหวัดจาก ททท.” ในเว็บ ข้อมูลเวลาเปิดบริการ กิจกรรมตามฤดูกาล และสภาพอากาศควรตรวจอีกครั้งก่อนเดินทาง
